# MIO QoL
Quality of Life changes for the game MIO: Memories in Orbit.

## Current Features
- Skip the intro sequence (cutscene + tutorial)
-

## Setup
1. MAKE SURE DOTNET 8 IS INSTALLED!!!
2. Install the [mod loader](https://github.com/MIO-Modding/mod-loader)
3. Run the game, and then close it
4. Download the most recent zip from releases and put it's contents in your mods folder. The path should look something like "MIO/mods/QoL/QoL.dll"
